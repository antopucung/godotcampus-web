# GodotCampus browser editor (built site)

This repository is the **deployed output** of the GodotCampus browser editor and
nothing else: Godot 4.7.1's web editor (MIT), the GodotCampus launcher
(`campus.html`), and one world bundle. It is generated by
`godotcampus-backend/scripts/build-web-shell.py` and `build-web-world.py` in the
private source repository; never edit it by hand.

Open `campus.html`. GitHub Pages cannot send the COOP/COEP headers the engine
needs, so on a first visit the launcher registers Godot's service worker (which
adds them) and reloads once.
